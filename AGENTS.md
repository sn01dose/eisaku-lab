# Project boundaries

- This directory is the root of the Eisaku Lab application.
- Do not create or modify application files outside this directory.
- Do not create a second nested Vite project.
- Use npm only. Keep one package.json and one package-lock.json.
- Place application source code under src/, learning content under src/data/,
  and design/education documents under docs/.
- Do not commit generated folders such as node_modules, dist, or coverage.
- Remove temporary files and unused scaffold files before finishing.
- Run npm run lint, npm run test, and npm run build after meaningful changes.
